# Project Charter

## Project Name

Singapore LinkedIn Job Market Analytics

## Purpose

Analyse Singapore job-posting data to understand which posting attributes are associated with higher visibility and application activity.

## Research Question

What factors make job postings more visible and increase application rates, and how can job seekers use these insights to improve their job search?

## Scope

In scope:

- data cleaning and preprocessing
- exploratory analysis of salary, posting duration, work arrangement, seniority, views, and applications
- visualisations and written insights
- reproducible data-preparation code
- DataOps documentation and CI checks

Out of scope:

- live scraping or automated collection from LinkedIn
- predictive modelling for hiring outcomes
- deployment as a production analytics service
- publication of restricted raw data

## Stakeholders

- student analyst: Goh Kun Ming
- academic reviewer: Senior Lecturer Goh Chia Ming
- target readers: students, job seekers, educators, and employers interested in Singapore labour-market trends

## Success Criteria

- The original CA1 analysis remains accessible.
- The repository can be installed and tested with standard Python tooling.
- Raw-data expectations are documented clearly.
- CI validates reusable code on every push and pull request.
- Documentation explains governance, ethics, and reproducibility.
